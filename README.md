# MyBatis Oracle Splitter

Please copy the file contents from the Claude artifacts to complete the project setup.

## Required Files

1. Copy `pom.xml` content
2. Copy all Java source files to appropriate directories
3. Copy `oracle-rules.yaml` to src/main/resources/
4. Copy `logback.xml` to src/main/resources/

## Build

```bash
mvn clean package
```

## Run

```bash
java -jar target/mybatis-oracle-splitter-1.0.0.jar --help
```
